# Android 客户端开发进度与方向确认

更新时间：2026-11-27

## 一、开发方向

当前实现符合已经确定的产品方向：

- 纯本地 Android 应用，不依赖现有 Go 服务或服务器转发。
- 学校账号登录、余额采集、历史展示、订单和充值均由 App 直接调用学校接口。
- Kotlin + Jetpack Compose Material 3。
- Room 保存宿舍、读数、通知和待支付状态。
- WorkManager 每 15 分钟检查一次到期宿舍，手动刷新强制采集全部宿舍。
- Android 原生通知，支持低余额、每日余额和登录失效提醒。
- 支持校园卡待支付订单、随机支付键盘和最终扣款流程。
- 充值身份验证开关默认关闭；开启后在进入充值和最终支付前要求指纹或设备凭据。
- 侧载 APK 交付，不建设 Play Store AAB 流程。
- 不导入旧 Go 服务的数据，不兼容服务器 webhook 或管理密钥。

如果以上边界没有变化，当前开发方向正确。

## 四、Android 签名 Key 状态

### 生产签名 Key

状态：未生成

当前没有生成可正式发布使用的 Android 签名 key。

签名 key 属于应用身份，后续所有升级 APK 必须继续使用同一份 key。它不应由代码仓库或 CI 临时生成，也不应提交到 Git。

正式签名需要用户自行生成并妥善离线备份：

```bash
keytool -genkeypair -v \
  -keystore wxxyshall-release.jks \
  -alias wxxyshall \
  -keyalg RSA \
  -keysize 4096 \
  -validity 10000
```

GitHub Release 使用以下 Secrets：

- `ANDROID_KEYSTORE_BASE64`
- `ANDROID_KEYSTORE_PASSWORD`
- `ANDROID_KEY_ALIAS`
- `ANDROID_KEY_PASSWORD`

状态：已生成，仅用于验证签名流程

路径：

```text
/tmp/wxxyshall-signing-check-20261127/release.jks
```

限制：

- 该 key 不是生产 key。
- 只在 `/tmp`，未提交到仓库。
- 仅用于确认 Gradle 签名配置和 APK 校验流程可用。
- 当前 `app-release.apk` 由该临时 key 签名，不能作为正式发布包。

Debug APK 使用 Android 默认调试证书，也只能用于本地安装测试。

纯本地 + Kotlin + Jetpack Compose + Room + WorkManager + 原生通知
